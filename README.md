# Foundry Clarion

Contact Centre as a Service (CCaaS) for the Foundry platform — a custom agent UI on
top of raw Twilio (TaskRouter, Voice), hosted on Cloudflare (Pages + Workers + D1 + R2).
Public URL: `clarion.foundry-ns.com`. (Renamed from "Foundry Connect" to avoid confusion
with Amazon Connect.)

See `CLAUDE.md` for the standing brief and `docs/design/foundry-clarion-design.md` for the
architecture. Implementation plan for the first phases:
`docs/superpowers/plans/2026-07-13-foundry-clarion-phase-0-1.md`.
